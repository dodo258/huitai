会话台ai

终端里敲 ai，各家 AI 的对话按项目列出来。
回车接着聊，关掉窗口照样在后台跑。

本机 Claude Code、Codex、pi、Hermes、Kimi Code、Gemini CLI、OpenCode、Antigravity 装了哪家就列哪家。它是装在终端里的命令行工具，不是终端，也不用 tmux：你照样用自己的 Ghostty、Kaku 或别的终端。

curl -fsSL https://github.com/dodo258/huitai/releases/latest/download/install.sh | sh

按芯片下载预编译的 ai，SHA256 对上才放进 ~/.local/bin，不用 sudo。只支持 macOS；回车在新标签页打开要 Ghostty 1.3 以上或 Kaku，别的终端在当前窗口打开。GitHub 上看源码

不改你的按键

会话台夹在中间时不改你的按键和输出。聊天标签页里，右边这些和直接跑 CLI 完全一样。

开着中文输入法也能直接按单键：会话台在前台时自动切成英文，离开切回；打出中文就直接开始搜索。

  • 换行Shift+Enter
  • 中文输入法照常打字
  • 标签页标题前面加上厂商标记和项目名 ✻ shop · …

隐私

只读本机
只读各家在本机的会话文件，不改它们的配置（~/.claude/settings.json、~/.codex/config.toml、~/.pi/agent/）。唯一会动厂商文件的是删除：移进会话台回收站，能恢复。
不上传
不上传对话，没有统计和遥测。改名、置顶、归档、设置都存在本机 ~/Library/Application Support/huitai/。
联网只有两处
  1. Claude 额度的备用渠道：状态栏的数据读不到时，用本机 Claude Code 的登录凭证问一次 Anthropic 官方用量接口，结果缓存 5 分钟；凭证只在内存里用，不存盘。
  2. 查新版本：每天最多一次，向 GitHub Releases 发一个不带任何个人信息的请求，3 秒没回就算了。不会自己更新。不想让它查，在设置里关掉「检查新版本」，或设 HUITAI_NO_UPDATE_CHECK=1。

和 Rex 有什么不同

Rex 是 Ghostty 作者的公司 Superlogical 在做的终端，2026 年 10 月起在 macOS 上公开测试。两者都能让 AI 对话关掉窗口照样跑、看得出哪条在等你；不同在下面几处。

会话台Rex
是什么

装在你现有终端里的一条命令 ai，Ghostty、Kaku 照用

一个独立的终端 App，替换你现在的终端

管哪些对话

本机各家的全部历史对话，按项目分组、全文搜索，回车接着聊

在 Rex 里开的会话；标出 Claude Code、Codex、OpenCode、pi 谁在干活、谁在等你

额度

顶栏显示 Claude、Codex 的限额窗口和 pi 的今日 token

官方资料里没提到

多台机器

只管本机

强项：连接别的机器上的 Rex 服务，iOS 等客户端在路上

怎么拿到

一行命令安装，MIT 开源

加入邮件列表等邀请，免费、不用注册账号

想换一个更强的终端、在几台机器之间接着干活，看 Rex；想继续用顺手的终端，把本机散落的 AI 对话找回来、接上、保活，用会话台。

Rex 的信息来自它的官网、公开测试公告和 CLI 文档，截至 2026 年 11 月；它还在测试，以官方为准。

装上试试

要 macOS。在新标签页打开对话需要 Ghostty 1.3 以上或 Kaku，别的终端在当前窗口打开。界面是简体中文。

curl -fsSL https://github.com/dodo258/huitai/releases/latest/download/install.sh | sh
cargo install --locked --git https://github.com/dodo258/huitai

第二行是从源码装，要最新的 stable Rust。在 macOS 27、Apple 芯片上开发和测试；Intel 版只做了构建，没有真机测过。
